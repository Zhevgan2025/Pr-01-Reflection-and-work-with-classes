# C# Reflection and Class Library Project

This is an academic C# project focused on reflection and working with class libraries.

## Features

- Working with a separate class library
- Reading class information at runtime
- Accessing properties and methods using reflection
- Creating objects dynamically
- Calling methods dynamically
- Practicing Object-Oriented Programming concepts

## Technologies

- C#
- .NET
- Reflection
- Class Library
- Object-Oriented Programming (OOP)

## What I learned

- How reflection works in C#
- How to inspect classes, properties, and methods at runtime
- How to work with external class libraries
- How to create and use objects dynamically
